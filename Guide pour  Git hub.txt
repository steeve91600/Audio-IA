------------EN TRADUISANT L ERREUR-----------

Vous pouvez soit spécifier l'URL depuis la ligne de commande, soit configurer un dépôt distant à l'aide de la commande :

git remote add <nom> <url>

puis effectuer le « push » en utilisant ce nom de dépôt distant :

git push <nom>

--------------ACTION EN CONSEQUENCE---------

git remote add max git@github.com:steeve91600/Apprendre-Django-en-mode-simple.git

git push --set-upstream max master

git push -u max main
------------------------------
